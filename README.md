### Tier 1: Real-World Applications
1. **[NCC Selection Portal](https://ncc-selection-portal.vercel.app)** · [GitHub](https://github.com/Mr-Raza-Alam/NCC_Selection_Portal)

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Mr-Raza-Alam/my_portfolio.git
   cd my_portfolio
   ```

2. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Build for production:**
   ```bash
   npm run build
   ```
